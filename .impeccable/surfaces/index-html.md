# Character studio

Scope: the active standalone ClipLab authoring studio. Operate mode for a product designer configuring characters, expression beats, looping sequences, and app or marketing exports.

The user explicitly replaced the pale inspector with dark-only floating cards: preview and sequence share the left column, inspector is its own right card, and the header is transparent. The character and its readable gestures stay central; sparse white selections show the active beat. The supplied white ClipLab SVG is binding.

The main preview supports actual CSS-size presets, true front orientation, and a position lock. Character controls include round eyes, bolder mouths, cheek cutouts, iris highlights, and camera-fixed radial toon bands. Secondary props and tears continue their eased loops when floating is locked. Saved projects and both export paths remain compatible.

User screenshots are the approved direction. No unresolved creative decisions remain for this refinement. Additional preset emotions remain user-editable.
